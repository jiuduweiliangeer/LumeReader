# 使用说明

## 首次启动和依赖

安装 Windows x64 版本后，从开始菜单或桌面快捷方式启动“轻阅 Lume Reader”，无需 Python 环境。内置转换可离线执行。

额外依赖按 [README 格式表](../README.md#格式与额外依赖) 判断。只有导出 MOBI / AZW3 需要 KindleGen；导入它们并转成 KFX / EPUB 等不需要。

[Amazon Kindle Previewer 官方页面](https://kdp.amazon.com/en_US/help/topic/G202131170) 提供桌面预览软件下载。部分发行版附带 `lib\fc\bin\kindlegen.exe`，新版内容可能变化。本软件也支持手动配置已安装的 KindleGen 或设置 `KINDLEGEN` 环境变量。

## 批量操作

添加书籍 → 勾选 → 选择输出 → 仅转换。结果出现在“已完成”。

- 每行复选框决定本次处理的书籍。
- “全选”针对当前可见行；过滤隐藏的书籍不参与批量操作。
- 支持多文件、文件夹递归导入、文件夹拖入；重复路径只登记一次。
- 移除选中 / 清空只操作队列，不删除原始书籍。
- 转换可取消；单本失败后继续下一本。

## 字体和封面

“阅读样式 → 排版”设置缩进、字号基准、行距、段距、对齐及 TTF / OTF。默认仅补齐缺失缩进。

字体默认只嵌入本书需要的字形；字体缺字时提示回退。在 Kindle 使用“出版商字体”。旧 MOBI7 与 TXT 不支持嵌入字体，FB2 的显示受阅读器限制。

“封面”选择 JPG / PNG / WebP 图片。这些设置只影响转换，“直接发送”保留原书内容。

## Kindle 传输与管理

用数据线连接并解锁 Kindle。新款 MTP 不需要盘符；旧款支持 USB 目录。

“直接发送”传输设备能阅读的现成文件。“转换并发送”在改格式、字体或封面之后自动传输。EPUB 不能仅靠改名发送，可先转 KFX / AZW3 / MOBI，或自行使用 [Send to Kindle](https://www.amazon.com/sendtokindle)。

“Kindle 书架”支持搜索、筛选、勾选、导出和删除。删除前备份并校验文件身份；原生收藏夹不在管理范围内。

### Voyage / 旧款 KFX 书架封面

连接 Voyage 后使用“转换并发送”，默认自动模式会选择旧款兼容格式并发送缩略图。仅转换时，在“设置 → KFX 封面兼容”选择“旧款 Kindle / Voyage”，转换后用软件发送。

旧版生成的 KFX 也可以重新导入，再转换为 KFX。若封面联网后消失，重连数据线并点击“刷新书架”。这只会恢复本软件发送过且书籍仍在设备上的封面；具体限制见 [Voyage 封面说明](VOYAGE_COVERS.md)。

## 历史、备份和卸载

删除已完成记录时，可选择是否一起移除转换输出；原始文件不会随记录删除。转换输出先备份到 `data/local-trash`，设备文件先备份到 `data/device-backups`。

安装版根目录为 `%LOCALAPPDATA%\LumeReader`，可从“设置与帮助 → 数据目录”打开。卸载保留这些文件。`LUME_DATA_DIR` 环境变量可指定独立数据根目录。

## 排查问题

| 现象 | 检查 |
|---|---|
| MOBI / AZW3 输出缺少编译器 | 配置真实存在的 kindlegen.exe；其他输出不受影响 |
| Kindle 未出现 | 检查数据线、解锁状态，手动刷新 |
| 字体未生效 | 格式是否支持、是否选择出版商字体、字体是否缺字 |
| 扫描 PDF 无可编辑文字 | 扫描页作为图片保留，没有 OCR |
| Previewer 拒绝 AZW3 | 它可能不支持该编译器输出；EPUB 检查不等同于 AZW3 实机检查 |
| 单本任务失败 | 查看错误和数据目录 data/logs 中的日志 |

反馈时避免公开整本书、账号、设备标识和个人路径。


## 1.1 新增功能

- 输出格式下方提前显示设备推荐；连接特殊机型时自动切换，手动选择的格式不会被周期刷新覆盖。设备栏可补充指定型号。
- 阅读样式顶部可选七种预设；预设控制默认排版和 PDF 页面尺寸，不改变字体和封面。
- 队列上方勾选“为每本书单独设置封面”，添加书籍后逐本确认；也可在封面页编辑已有选择。
- “摘抄”页从 Kindle 读取或导入 My Clippings.txt，重复记录去重，按书籍查看；100 条一页，支持搜索、类型筛选和 ENEX / Markdown 导出。
- ENEX 为印象笔记 / Evernote 文件导入格式，每本书一条笔记；导出当前书籍时包含该书全部摘抄，不受搜索或类型筛选影响。
- 选择内置字体即可嵌入；其他字体可放入自定义字体文件夹。详见 [字体说明](FONTS.md)。
