# 验证记录

## 开发阶段，2026-11-03 至 2026-11-04

- 45 项自动测试通过，覆盖编码、章节、字体、封面、PDF 图片、同名保护、直接发送、备份、删除、勾选、主题和后台队列。
- 49 组矩阵：EPUB、MOBI、AZW3、KFX、PDF、HTML、FB2 各转另外 7 种目标格式；回读生成物，检查中英文正文标记，并记录目录、字体、封面。
- 5 组现有书籍：EPUB→KFX、MOBI→EPUB、AZW3→KFX、PDF→EPUB、长篇 KFX→AZW3。共 54 组通过。
- 现有书籍检查输入哈希不变、全文可回读、正文长度及分段样本；不代表逐页人工核对。
- Kindle Previewer 核对了 MOBI→EPUB 以及长篇 KFX→AZW3 回读 EPUB 的封面、目录、标题和字体；后者是间接检查，Previewer 拒绝直接预览该 AZW3。
- MTP 实机验证书架读取及独有临时文件的发送、导出、备份、删除，保留原有图书。

## 本机参考耗时

约 250 万字、789 个目录节的 TXT，包含字体处理，首轮单次测试：

| 输出 | 耗时 |
|---|---:|
| EPUB | 6.39 秒 |
| AZW3 | 19.84 秒 |
| KFX | 22.04 秒 |
| PDF | 42.58 秒 |

不是跨设备保证，也未与 Calibre 同条件对比。字体、封面、版本与缓存影响结果。

测试小说、私人书架、用户字体与本机日志不公开分发。公开测试采用最小自编内容，见 tests/ 与 examples/。

## Windows 1.0.0 发布验证

- 独立 LumeWorker.exe 自检通过：Python 3.9.23、Qt 6.6.3 / PyQt 6.6.1；不调用 Calibre。
- 清除 Python / Conda 路径变量、PATH 只保留 Windows System32，使用带空格的数据目录，完成 7 次样本生成及 49 组非 TXT 输入互转，共 56 次，全部成功。
- 逐项回读输出，校对自编示例的中英文正文标记，记录章节、目录、字体与封面。MOBI / AZW3 输出使用单独配置的 KindleGen；编译器不在安装包内。
- 独立 GUI 导入 EPUB、选择输出目录、触发后台 KFX 转换，生成结果成功；文件选择窗口保持浅色主题。
- WPD / COM 初始化与只读设备扫描通过。打包检查时未连接 Kindle，未将此项计为设备传输实测；前期的实机验证见上文。
- Inno Setup 6.7.3 编译成功，安装包中的文件解压完成。当前自动化环境拒绝写入 Windows 卸载注册表，安装随后自动回滚；完整注册安装和正常卸载尚未在该环境验证。
- 安装脚本将用户数据放在安装目录之外，未设置删除用户数据的卸载规则；这属于脚本检查结果，并非完整卸载实测。

可复现转换验证：设置可选的 `KINDLEGEN`、`LUME_TEST_FONT`，运行 `python packaging/verify_bundle.py`。缺少 KindleGen 时仅验证无需外部编译器的格式。公开仓库只包含自编示例，不包含原测试小说、私人字体、设备书架或本机授权数据。
