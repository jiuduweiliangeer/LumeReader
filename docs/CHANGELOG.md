# 1.1.0

- 修复 Voyage 等旧款 Kindle 的 KFX 书架封面兼容，增加已发送封面的缓存恢复。
- 修复帮助文档中文正文丢失与 Markdown 表格渲染，统一明亮主题。
- 批量书籍增加逐本封面复选框和设置向导，直接发送继续保留原文件。
- 增加七种阅读预设，PDF 页面尺寸跟随设备尺寸。
- 连接设备后提前显示格式推荐与原因；支持自动型号识别和手动指定。
- 内置霞鹜文楷、汇文明朝、悠哉字体及各自许可；保留自备字体支持。
- 新增摘抄页：USB / MTP 读取或文件导入，按书籍分类、搜索、分页、去重；窄书名栏、宽阅读区和居中的操作区。
- 主导航去掉编号，可收起为图标栏并记住状态。
- 检测本机笔记软件，支持 Obsidian / Logseq 文件库直接写入、Joplin 本地接口导入，以及 ENEX / Markdown ZIP 接收流程；保留通用文件导出。

Voyage 真机书架显示需在设备上复核；代码与模拟 USB 目录已验证文档类型、封面命名、同步和恢复。详情见 [Voyage 封面说明](VOYAGE_COVERS.md)。
