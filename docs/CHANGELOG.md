# 1.1.0

- 已内置 KindleGen，AZW3 / MOBI 无需额外安装或手动配置。
- Kindle Voyage 推荐使用 AZW3，连接后自动显示推荐格式，也可手动切换。
- 优化 Voyage 等旧款 Kindle 的 KFX 书架封面兼容，增加已发送封面的缓存恢复。
- 修复帮助页中文正文、表格及图片显示，统一明亮主题。
- 批量转换开始时询问是否逐本设置封面，并提供选图向导；添加书籍和直接发送不弹窗。
- 增加七种阅读预设，支持自定义排版，PDF 页面尺寸跟随设备尺寸。
- 连接设备后提前显示格式推荐与原因，支持自动识别和手动指定型号。
- 内置霞鹜文楷、汇文明朝、悠哉字体，保留自备字体入口。
- 新增摘抄页，按书籍分类查看划线、笔记与书签，支持搜索、分页和重复导入去重。
- 优化摘抄布局：左侧窄书名栏、右侧阅读区，导入与保存操作集中在顶部。
- 主导航去掉编号，支持收起为图标栏并记住状态。
- 自动检测笔记软件，支持按目标转换摘抄、导入或打开文件导入流程，保留 ENEX / Markdown 导出。
- 设置页展示转换组件状态；原有外部编译器路径失效时自动回退到内置组件。
